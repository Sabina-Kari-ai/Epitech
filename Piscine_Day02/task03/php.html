PHP

PHP is a general-purpose scripting language geared towards web development. It was created by Danish-Canadian programmer Rasmus Lerdorf in the 1990s and later became maintained by the PHP Group. The name originally referred to Personal Home Page and today means PHP: Hypertext Preprocessor.
